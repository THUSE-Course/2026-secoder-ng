# 五个入口，覆盖学生最常见的工作

| 入口 | 你在这里完成什么 | 什么时候打开 |
| --- | --- | --- |
| SECoder | 账号、组队、邀请、个人资料、Kubernetes 凭据 | 第一次使用或权限变化 |
| GitLab | 仓库、分支、MR、CI/CD、镜像 | 每天开发和提交 |
| SonarQube | 代码质量、Bug、漏洞、代码异味 | 提交或合并前 |
| Headlamp | Kubernetes 资源、Pod、日志、命名空间 | 部署和排障时 |
| Grafana | 指标、趋势、监控和告警 | 运行异常或复盘时 |
